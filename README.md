# Flow 1.2

Исправленная версия адаптивного органайзера для Windows и браузера.

## Что исправлено

- «Вечерний фон» теперь переключает тёмную тему и запоминает выбор.
- Деление задачи работает через Claude, а без ключа использует локальный запасной алгоритм.
- Интерфейс сообщает, если локальный сервер недоступен.
- Service Worker больше не удерживает устаревшую версию интерфейса.
- База и секрет создаются в отдельной папке данных; при запуске создаётся ежедневная резервная копия.
- Добавлена валидация email, пароля и изменяемых полей задач.
- Сервер слушает только локальный адрес `127.0.0.1`.
- Добавлена сборка полноценного Windows-приложения через Electron.
- Добавлена автоматическая проверка обновлений через GitHub Releases.

## Быстрый запуск для проверки

```powershell
npm.cmd install
npm.cmd start
```

Откройте http://127.0.0.1:3000.

## Запуск настольной версии

```powershell
npm.cmd run desktop
```

## Создание установщика Windows

```powershell
npm.cmd run dist:win
```

Готовый установщик появится в папке `dist`.

## Публикация обновления

1. Измените поле `version` в `package.json`, например на `1.2.1`.
2. Отправьте изменения в GitHub.
3. Создайте и отправьте тег с такой же версией:

```powershell
git tag v1.2.1
git push origin v1.2.1
```

GitHub Actions соберёт установщик и опубликует Release вместе с файлами обновления. Уже установленный Flow проверит GitHub при следующем запуске, предложит загрузку и сохранит пользовательские данные.

## Настройка Claude

Скопируйте `env.example` в `.env` и укажите настоящий `ANTHROPIC_API_KEY`. Не публикуйте `.env` и не отправляйте его другим людям. Без ключа добавление задач и локальное деление продолжают работать.

## Данные

В режиме браузера данные находятся в `data`. В установленном приложении Electron они хранятся в пользовательской папке Flow. Папка `backups` содержит ежедневные копии базы.

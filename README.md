# Flow — адаптивный органайзер

Полноценное веб-приложение с бэкендом: регистрация/вход, разговорный ввод дел (через Claude), адаптивный список под уровень энергии, вечерний anti-todo лог, недельный обзор, шаринг списка по коду, тихие напоминания. Устанавливается на телефон и компьютер как приложение (PWA).

## 1. Что нужно перед запуском

- Node.js 18 или новее (для встроенного `fetch`)
- Ключ Anthropic API — получить на https://console.anthropic.com (раздел API Keys). Обратите внимание: каждый вызов "разбора текста" и "разбивки на шаги" тратит платный запрос к API.

## 2. Установка и локальный запуск

```bash
cd flow-app
npm install
cp .env.example .env
```

Откройте `.env` и впишите:

```
ANTHROPIC_API_KEY=sk-ant-ваш-ключ
JWT_SECRET=любая-длинная-случайная-строка
PORT=3000
```

Запуск:

```bash
npm start
```

Откройте http://localhost:3000 — там же экран регистрации.

## 3. Деплой в интернет (чтобы работало не только на вашем компьютере)

Проще всего — хостинги с бесплатным тарифом и постоянным диском (нужен для файла базы данных `db.json`):

**Render.com**
1. Загрузите папку `flow-app` в GitHub-репозиторий
2. На render.com → New → Web Service → подключите репозиторий
3. Build command: `npm install`, Start command: `npm start`
4. В разделе Environment добавьте `ANTHROPIC_API_KEY` и `JWT_SECRET`
5. Добавьте Persistent Disk (иначе база данных будет сбрасываться при перезапуске)

**Railway.app** — аналогично, ещё проще через `railway up` из CLI.

После деплоя вы получите публичный адрес вида `https://flow-xxxx.onrender.com` — именно его открывать с телефона.

> Важно: `db.json` — простая файловая база для MVP на одного/нескольких пользователей. Для более серьёзной нагрузки стоит перейти на настоящую БД (Postgres) — дайте знать, если понадобится это сделать.

## 4. Установка как приложение на телефон

**iPhone (Safari):** открыть сайт → кнопка "Поделиться" → "На экран «Домой»"
**Android (Chrome):** открыть сайт → меню (⋮) → "Установить приложение" / "Добавить на главный экран"

После этого иконка Flow появится как обычное приложение, будет открываться в полноэкранном режиме.

## 5. Установка как приложение на компьютере

**Chrome/Edge:** открыть сайт → иконка установки в адресной строке (или меню → "Установить Flow") → приложение откроется в своём окне, появится в списке программ.

## 6. Структура проекта

```
flow-app/
  server.js          — весь бэкенд (Express + JSON-база lowdb)
  package.json
  .env.example
  public/
    index.html        — весь фронтенд
    manifest.json      — описание PWA
    service-worker.js  — офлайн-кеш статики
    icons/             — иконки приложения
```

## 7. Что можно улучшить дальше

- Настоящая база данных (Postgres/SQLite с миграциями) вместо JSON-файла
- Восстановление пароля по email
- Push-уведомления вместо тихого тоста внутри окна (потребует дополнительной настройки — Web Push API)
- Более гибкий шаринг (несколько списков, права на редактирование)
